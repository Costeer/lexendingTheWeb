# Store graphics

- `screenshot-*.png`: 1280×800 full-bleed listing screenshots for Chrome and Firefox
- `small-promo.png`: 440×280 Chrome Web Store small promotional tile
- `marquee-promo.png`: 1400×560 optional Chrome Web Store marquee image
- `*-promo.svg`: editable sources for the promotional images

The screenshot dimensions follow the current Chrome Web Store requirement and
Firefox recommendation. Re-capture screenshots whenever the popup changes so
the listing continues to represent the shipped interface accurately.
