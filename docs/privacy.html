LEXEND THE WEB

Privacy Policy

Last updated: September 19, 2026

Lexend the Web does not collect, transmit, sell, or share personal data.

Data stored by the extension

The extension stores whether it is enabled, global and per-site text scope, optional text-size and spacing preferences, and user-created hostname rules. These settings use the browser's synchronized extension storage. Lexend the Web does not operate a server and cannot access the user's browser-sync account.

Website access

The extension runs on HTTP and HTTPS pages to replace visible typography with the locally bundled Lexend font. Page contents are processed only inside the browser and are never recorded or transmitted. Browser-protected pages cannot be accessed.

Settings files

Settings JSON files are imported and exported locally. The extension never uploads them.

Third parties

The extension contains no analytics, advertising, remote code, trackers, or third-party network services. Lexend is packaged with the extension.

Changes and contact

Material changes will be documented in release notes. Questions may be filed through the GitHub issue tracker.
